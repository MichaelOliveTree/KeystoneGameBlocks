on living in a simulation


I watched "Everything, Everwhere, All at Once" yesterday and it portrays an environment where there are virtually infinite parallel universes.  It claimed that every choice can lead to a different life experience for everyone.

but this made me think about the issue of determinism.  If the universe is deterministic and each universe has the same starting conditions, then there shouldn't be any changes between the universe.  Each living organism given the same conditions at a specific time, does not just make random decisions, but a deterministic "choice" based on it's current state and the state of the environment and history.  

There is no "free will."
